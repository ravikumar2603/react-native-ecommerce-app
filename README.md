# React Native E-Commerce App 🛍️

A cross-platform single-page e-commerce application built with React Native and Expo SDK 54.

## Features
- Cross-platform: Android, iOS & Web
- Responsive category panel (top on mobile, left on web)
- Scroll-synced category selection
- Cart management using React Context + useReducer
- Toggle add/remove buttons with visual feedback

## Tech Stack
- React Native / Expo SDK 54
- React Context API + useReducer
- JavaScript (ES6+)
